Admin Console — enrolment, exercise library, active routine

This is the admin tool (Option A, no backend). Everything runs locally in your browser. You download the generated files (bank.json, references/<id>.json, routines.json) and commit them to the repo; the kiosk app reads them on load. Demo use only — no access control, use tester data only.

Enrol People → bank.json

Drop a clear, front-facing photo on each slot, type the name, and set weight (kg). The browser computes a 128-D face descriptor and a 160×200 thumbnail. Click Download bank.json and commit it to the repo root.

Deploy checklist
1. Commit bank.json to the repo root (People tab).

3. Commit routines.json to the repo root (this tab) — the routine with the Active radio gets "active": true.
4. Confirm each routine's YouTube video has embedding allowed.
5. The kiosk reads these on load — no code changes needed.
